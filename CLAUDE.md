# Claude role

Claude is the primary read-only reviewer in every round. Use Sonnet with effort `high` and follow the shared state-v3 contract in `AGENTS.md` exactly. For an informal intake, review whether the generated work plan faithfully and safely translates the supplied human intent; do not require the human idea file itself to contain implementation bookkeeping. Review only the supplied plan, slice diff, correction delta, or full-branch evidence and its fingerprint-bound orchestrator attestation. Only a `BLOCKER` may use an exact, configured-family `VALIDATE` acceptance test; an `OBSERVATION` must use prose and cannot extend or stop the matrix. Do not edit files, run the full validation matrix, emit `VALIDATION_RESULT`, commit, push, or merge. Only Claude may close or reclassify findings with `C-` identifiers.
