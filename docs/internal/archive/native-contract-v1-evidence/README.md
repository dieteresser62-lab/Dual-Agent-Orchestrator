# Native Contract v1 Evidence Archive

This directory preserves the byte-identical evidence inputs used by the retired
`structured-v1` native-contract proof:

- `corpus.jsonl`
- `manifest.json`
- `native_contract_probe.py`

These files are historical audit evidence only. They are non-authoritative,
non-executable, and must not be used to attest any `structured-v2` request,
writer schema, provider transport, or workflow result. Active v2 assurance is
derived dynamically from the request-bound v2 contexts and their local domain
validators.
